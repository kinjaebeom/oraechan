# 디자인 기준 — 파송 UI 기반 오래찬

## 기준과 현재 적용 범위

사용자가 지정한 [파송 UI 인터랙티브 프로토타입](references/pasong-ui-prototype.html)을 향후 화면의 시각적 기준으로 사용합니다. 원본 파일은 수정 없이 보관합니다. **서비스명은 오래찬(Oraechan)**이며, 원본의 파송/PASONG 텍스트는 제품 UI 구현 시 오래찬으로 변경합니다.

현재 적용한 것은 색상 토큰과 서비스명/슬로건을 표시하는 최소 시작 페이지뿐입니다. 아래 레이아웃·컴포넌트·인터랙션은 모두 향후 작업입니다. 원본의 코드, 임시 데이터, 저장소 키와 추천 규칙을 그대로 제품에 이식하지 않습니다.

## 방향

따뜻한 찬송가 책과 묵상집을 현대적으로 재해석합니다. 크림색 배경, 숲색 텍스트와 버튼, 넉넉한 여백, 명조 제목, 아치형 풍경 그래픽, 둥근 카드와 필 버튼을 따릅니다. 종교적 장식을 과도하게 사용하지 않습니다.

전역 CSS에는 동일한 이름의 Tailwind `--color-*` 토큰을 정의했습니다. 원본 그림자는 `0 12px 38px rgba(27,54,39,.07)`입니다. 실제 버튼/카드가 생길 때 필요 토큰을 추가합니다.

초안의 Forest `#2F5D46`, Ivory `#F7F3EB`, Sage `#C9D7C5`, Sand `#D7C2A3`, Gold `#B08B57`, Brown `#7A6148`은 이전 제안으로 기록하며, **현재 디자인 기준은 파송 팔레트**입니다.

## 타이포그래피

원본은 제목에 Georgia/Noto Serif KR 계열, 본문에 Pretendard 계열의 폴백 스택을 선언하지만 실제 웹폰트 파일을 포함하지 않습니다. 현재는 외부 폰트 없이 시스템 고딕/명조 폴백을 사용합니다. 본격 UI 구현 시 MaruBuri·Pretendard 또는 대체 폰트의 웹 배포 라이선스와 서브셋/로딩 성능을 확인한 뒤 적용합니다.

## 향후 화면 구성

1. 상단: 워드마크, 탐색·나의 찬양·소개, 언어 전환.
2. 히어로: 슬로건, 설명, 시작 버튼과 아치형 풍경.
3. 감정 카드와 원하는 메시지 선택 필.
4. 추천 안내, 검색/필터, 찬양 카드 그리드.
5. 상세 정보와 공식 영상 접근, 서비스 이야기와 푸터.

원본의 최대 콘텐츠 폭은 1250px, 수평 패딩 26px, 데스크톱 감정/곡 카드는 3열입니다. 실제 모바일 구현에서는 읽기 순서를 유지하고 화면 폭에 맞춰 열을 줄입니다. 원본의 상세 모달은 제품의 고유 상세 URL 요구사항과 조율해야 합니다.

## 접근성과 상호작용 원칙

선택 상태는 색상 외에도 텍스트/체크 표시와 `aria-pressed`로 표현합니다. 실제 링크는 링크로, 동작은 버튼으로 구현합니다. 키보드 포커스, 명도 대비, 클릭 영역, 확대와 reduced-motion을 확인합니다. 특히 원본의 연한 작은 텍스트는 그대로 확정하지 않고 WCAG AA 기준으로 검토합니다. 모달을 채택한다면 포커스 이동·가두기·복귀, Escape 종료, 레이블을 구현합니다.

프로토타입의 YouTube 검색 링크는 최종 재생 기능이 아니며, 공식 영상 검증 후 별도로 구현합니다. 실제 로고 제작과 전체 UI 퍼블리싱은 Phase 0에 포함하지 않습니다.

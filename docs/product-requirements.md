# 오래찬 서비스 요구사항

## 목적과 범위

미션: 오래된 찬양의 가치를 오늘의 청년들에게 다시 연결한다.
메인 슬로건: 오늘의 마음에, 오래된 찬양 한 곡.
보조 슬로건: 오래된 찬양, 오늘의 위로.

주요 사용자는 마음에 맞는 찬양과 묵상할 메시지를 찾고 싶은 사람입니다. 로그인 없이 발견·소개 읽기·공식 영상 감상·즐겨찾기·공유를 이용하도록 설계합니다. 특정 감정을 강요하거나 치유를 보장하지 않습니다.

현재 구현: Pages Router 기반 최소 시작 페이지와 개발 도구 설정뿐입니다. 아래 기능은 모두 **향후 구현 요구사항**입니다.

## 핵심 흐름

접속 → 현재 감정 선택 → 원하는 메시지 선택 → 3~5곡 추천 → 추천 이유와 소개 확인 → 공식 영상 감상 → 즐겨찾기 또는 상세 URL 공유.

## 콘텐츠 원칙

- 장르는 전통 찬송가, 오래 사랑받은 CCM, 현대 CCM으로 구분합니다. 초기 큐레이션은 앞의 두 장르를 중심으로 합니다.
- '파송의 노래', '사명'은 CCM으로 분류합니다. 곡의 연대나 창작자 정보는 확인된 출처만 사용합니다.
- 소개글과 추천 이유는 독창적으로 작성하고, 가사·악보를 무단 복제하거나 번역하지 않습니다.
- 영상별 공식 출처와 임베드 가능 여부를 확인합니다. 음원이나 영상을 다운로드해 저장하지 않습니다.
- 프로토타입에 포함된 곡 설명·크레딧은 검증된 서비스 데이터로 간주하지 않습니다. YouTube 검색 링크도 공식 영상 검증을 대체하지 않습니다.

## 제약과 비목표

별도 백엔드·DB·계정은 사용하지 않습니다. 즐겨찾기는 해당 브라우저에만 남으며, 삭제되거나 다른 기기에서 동기화되지 않을 수 있습니다. 추천은 AI가 아닌 규칙 기반입니다. 실험 POC를 통계적으로 유의미한 A/B 결과라고 주장하지 않습니다.

공개 댓글·사용자 간 공유 피드·계정 동기화·수익화는 초기 MVP 범위 밖입니다. 콘텐츠 선정, 추천 가중치/동점 처리, 외부 폼 및 분석 서비스는 후속 단계에서 결정합니다.
